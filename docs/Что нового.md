# SoftProjector: что нового

*Для медиакоманды церкви · октябрь 2026 · ветка `update-2.2`*

Программа та же, к которой все привыкли: Библия, песни, программа служения, объявления. Всё старое работает по-прежнему, песни и тексты Библии сохранены. Ниже собрано, что добавилось и как этим пользоваться.

## 1. Быстрая смена перевода Библии

Справа от поля «Стих» появился список **«Перевод:»**. Выберите в нём перевод, и всё переключится сразу:

- переключаются **оба экрана** (основной и дополнительный);
- если стих уже на экране, он сразу показывается в новом переводе, то же место и те же стихи;
- если выбранный перевод раньше показывался вторым, переводы просто меняются местами.

**F11** выбирает следующий перевод по кругу, без мыши.

**Как добавить новый перевод.** Через «Управление базой данных» (**Ctrl+M**) → Библии: импорт модуля из файла или загрузка из интернета. Новый перевод сразу появится в списке «Перевод:».

## 2. Выбор куплетов песни

Иногда поём не всю песню, а, например, 1, 3 и 5 куплеты. Теперь это можно отметить, **не меняя песню в сборнике**:

1. Во вкладке «Песни» выберите песню.
2. В списке куплетов (по центру) **снимите галочки** с тех, что петь не будем. Припев показывается как обычно.
3. На экран и в стрелки PgDown/PgUp попадают только отмеченные куплеты.

Если такую песню добавить в **программу служения**, выбор куплетов сохраняется вместе с программой. В списке программы рядом с названием видно, какие куплеты взяты:

> Например: 245 Велик Господь **(1,3,5)**

Если взяты все куплеты, скобок нет.

## 3. Горячие клавиши

Клавиши теперь можно назначить почти на любое действие: **Настройки (Ctrl+T) → «Горячие клавиши»**.

- На одно действие можно назначить до трёх клавиш.
- Если клавиша уже занята другим действием, программа это покажет.
- Кнопка **«По умолчанию»** возвращает стандартные клавиши.
- Клавиши работают, только когда **окно SoftProjector активно**. В других программах они ничего не делают.
- На кнопках подписана текущая клавиша, например «На экран (F5)». Если её поменять, подпись тоже поменяется.

**Стандартные клавиши**

| Клавиша | Действие |
|---|---|
| **F5** | На экран (из текущей вкладки) |
| **PgDown / PgUp** | Следующий / предыдущий стих, куплет или слайд |
| **Esc** | Скрыть (показать фон) |
| **Shift+Esc** | Убрать текст с экранов |
| **F4** (а также Shift+F5, Ctrl+Shift+B) | Показать на экранах снова |
| **F12** | Вернуться к презентации на тот же слайд |
| **F6** | Библия: поиск книги |
| **F9** | Библия: поиск по тексту |
| **F11** | Следующий перевод Библии |
| **F7** | Песни: поиск песни |
| **F8** | Объявления |
| **F2** | Добавить в программу служения |
| **Delete** | Убрать из программы |
| **Ctrl+PgDown / Ctrl+PgUp** | Следующий / предыдущий пункт программы сразу на экран |
| **Ctrl+O / Ctrl+S / Ctrl+Shift+N** | Открыть / сохранить / новая программа |
| **Ctrl+T** | Настройки |
| **Ctrl+M** | Управление базой данных |
| **F1** | Справка |

Без клавиш по умолчанию, но их можно назначить: вкладки «Презентации», «Картинки», «Медиа», первый и последний стих/куплет/слайд, видео (пуск/пауза, стоп), включение и выключение экранов.

> **Кликер.** Большинство кликеров для презентаций нажимают PgDown/PgUp. Поэтому кликером можно листать стихи, куплеты и слайды, пока окно SoftProjector активно.

## 4. Исправление текста стиха

Нашли опечатку в стихе? Во вкладке «Библия» щёлкните по стиху **правой кнопкой** → **«Исправить текст стиха…»**, поправьте текст и сохраните.

- Меняется только этот перевод и только в базе программы на этом компьютере.
- Если стих уже на экране, он сразу обновится.

## 5. Исправленные переводы Библии

При первом запуске новой версии программа сама исправляет тексты в базе. Перед этим она делает резервную копию базы, файл `spData.sqlite.bak`.

**Русский Синодальный перевод**
- 588 исправлений текста (их подготовил друг церкви): лишние пробелы, знаки, опечатки.
- Название: «Русский Синодальный Перевод». Книги называются «Песнь Песней» и «Иуды».
- Исправлено число глав в 3 и 4 Царств и нумерация в некоторых псалмах.
- Убран повтор стиха Пс 146:6.

**Новый русский перевод (НРП)**
- Перевод называется по-русски: «Новый русский перевод», сокращение НРП.
- Названия и порядок книг теперь такие же, как в Синодальном.
- Убраны лишние сноски вида «[1]» в тексте.
- **Нумерация стихов совпадает с Синодальным.** Раньше в псалмах при показе двух переводов рядом НРП мог показывать соседний стих. Теперь на обоих экранах один и тот же стих.

## 6. Презентации

Новая вкладка **«Презентации»** стоит сразу после «Песен». Здесь показываются:

- **PDF**;
- **PowerPoint** (`.pptx`, `.ppt`). На компьютере должен быть установлен PowerPoint;
- **картинки** (одна картинка или целая папка картинок как одна презентация).

**Как открыть**
- **«Открыть файл…»**: презентация из любой папки (флешка, загрузки и т. п.).
- **«В библиотеку»**: копирует презентацию в папку **«Презентации»** рядом с программой. Там удобно держать постоянные презентации, например с объявлениями. Библиотека хранится только на этом компьютере и через GitHub не передаётся.
- **«Удалить из библиотеки»**: файл уходит в Корзину, его можно восстановить.

**Первое открытие PowerPoint-файла занимает время.** Программа просит PowerPoint превратить слайды в картинки, внизу видно «Подготовка слайдов: 5 из 40». Потом готовые слайды запоминаются, и в следующий раз презентация откроется сразу. Если файл изменить, слайды подготовятся заново автоматически.

**Как показывать**
- **Двойной щелчок** по слайду выводит его на экран.
- Дальше листайте **PgDown/PgUp**, кликером или стрелками.
- В правой панели слайды крупные, во всю её ширину. Текущий слайд наверху, следующие под ним. Колёсико мыши прокручивает плавно.
- **Пробел** или **Ctrl + двойной щелчок**: посмотреть слайд крупно в отдельном окне, **не выводя его на экран** (например, чтобы прочитать мелкий текст).
- Размер слайдов во вкладке: ползунок внизу или **Ctrl + колёсико мыши**.

**Стих во время проповеди.** Проповедник попросил показать стих: показываете его как обычно из вкладки «Библия». Чтобы вернуться к презентации на **тот же слайд**, нажмите **F12** или кнопку на панели инструментов.

**Ограничения:** видео и анимация внутри PowerPoint не воспроизводятся, показываются статичные слайды. Скрытые слайды пропускаются. В программу служения презентации пока не добавляются.

## 7. Карта Blackmagic (вывод на ATEM без OBS)

Раньше второй экран для трансляции шёл через дополнительный экран Windows и OBS. Теперь SoftProjector сам выводит изображение на карту **Blackmagic DeckLink Mini Monitor**, а с неё сигнал идёт на **ATEM Mini Pro**.

**Настройка (один раз)**
1. Должен быть установлен драйвер **Blackmagic Desktop Video**.
2. Настройки (**Ctrl+T**) → «Общие» → **«Дополнительный экран:»** → выберите **«Карта Blackmagic: DeckLink Mini Monitor»**.
3. **«Формат сигнала карты:»** выберите тот же, что настроен в ATEM (обычно **1080p 25**).
4. Сохраните. Дальше карта работает как обычный второй экран, со своими настройками оформления для дополнительного экрана.

Если карта не найдена или занята другой программой (например, OBS), SoftProjector об этом сообщит. Закройте OBS или отключите в нём вывод на карту.

## 8. Стабильность

Мы прогнали программу через тысячи случайных действий подряд и исправили всё, на чём она падала или зависала:

- **Видео из программы служения** могло навсегда «повесить» программу при нажатии «На экран». Теперь, если файл не загрузился за 15 секунд (например, удалён или повреждён), программа просто не начинает показ.
- **Длинный или крупный текст.** Если текст никак не помещался на экран (огромные поля, очень длинная подпись), экран зависал навсегда. Теперь такого не бывает, а показ целой главы стал примерно в 3 раза быстрее.
- **Поиск по Библии** по одной букве или очень частому слову находил ~31 000 стихов, и программа «думала» 6–8 секунд и дольше. Теперь в списке первые 1000 результатов, а общее число написано рядом.
- **Второй запуск.** Если случайно дважды запустить SoftProjector, вторая копия скажет «SoftProjector уже запущен» и закроется, а не будет спорить с первой за экран и базу.
- **Зависший PowerPoint** (повреждённый файл, скрытое окно с вопросом) больше не держит подготовку слайдов вечно: через 3 минуты без прогресса программа сообщит об ошибке.
- **Повреждённые модули** песен и Библий при импорте больше не вешают программу.
- **Апострофы** в названиях песен, файлов и настройках больше не мешают сохранению. Раньше такое просто молча не сохранялось.
- Убраны вылеты в разных редких ситуациях: «На экран», когда ничего не выбрано; поиск «в текущей книге», когда книга не выбрана; изменение размера окна во время показа презентации; закрытие программы во время подготовки слайдов и другие.

## Для ответственного за компьютер

Программа на церковном компьютере лежит в папке **`D:\Old\SoftProjector`**. Перед любыми командами **закройте SoftProjector**, откройте командную строку и перейдите в эту папку:

```
D:
cd Old\SoftProjector
```

**Первый переход на новую версию (один раз).**

```
git fetch
git checkout update-2.2
```

`git fetch` скачивает с GitHub сведения о новых версиях, но ничего в папке не меняет. `git checkout update-2.2` переключает папку на новую версию.

**Следующие обновления.** Когда появится свежая версия, достаточно одной команды:

```
git pull
```

`git pull` сам скачивает новое (как `git fetch`) и сразу подставляет его в папку. Отдельный `git fetch` здесь не нужен: без `git pull` папка осталась бы на старой версии.

**Откат на прежнюю версию**, если что-то пошло не так прямо перед служением:

```
git checkout main
```

Вернуться обратно на новую версию: `git checkout update-2.2`. Песни и тексты Библии при переключениях остаются на месте, исправления текстов тоже.

**Резервная копия базы.** Перед исправлением переводов программа сохранила копию базы: `D:\Old\SoftProjector\spData.sqlite.bak`. Саму базу `spData.sqlite` в GitHub мы не меняем, все изменения текстов применяются прямо на этом компьютере.

**Ещё не проверено на настоящем оборудовании** (на тестовом компьютере всё работает):
- PowerPoint-презентации (нужен установленный PowerPoint);
- карта Blackmagic DeckLink и ATEM.

Если что-то не так, напишите, что делали и что увидели. Лучше со снимком экрана.
